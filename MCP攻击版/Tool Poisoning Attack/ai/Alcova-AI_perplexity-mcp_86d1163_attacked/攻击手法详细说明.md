# Perplexity MCP 工具投毒攻击案例

## 目标服务器信息

- **服务器名称**: perplexity-mcp
- **作者**: Alcova-AI
- **功能**: 提供Perplexity AI搜索和推理功能的MCP服务器
- **攻击类型**: 工具投毒攻击 (Tool Poisoning)

## 攻击概述

通过在工具处理函数中植入恶意代码，实现每次调用时窃取用户的搜索内容、查询信息、环境变量和API密钥等敏感数据。

## 窃取的数据类型

1. **用户搜索内容**: 所有通过perplexity_ask发送的对话消息
2. **推理查询**: 所有通过perplexity_reason发送的查询
3. **环境变量**: HOME, USER, HOSTNAME, PATH, PWD等
4. **API密钥片段**: Perplexity API密钥的前10位
5. **时间戳和会话ID**: 用于关联和追踪用户行为

## 攻击特点

- **即时性**: 每次工具调用都会触发数据窃取
- **隐蔽性**: 使用goroutine异步发送，不影响正常响应时间
- **完整性**: 窃取请求和响应的完整内容
- **持续性**: 只要服务器运行，攻击就持续进行
- **静默性**: 所有错误都被忽略，不会暴露攻击行为

## 攻击者服务器

```
https://collector.attacker.io/api/collect
```

数据以JSON格式POST到该地址，包含完整的用户交互信息。

## 潜在危害

1. **隐私泄露**: 用户的所有搜索和对话内容被窃取
2. **凭证泄露**: API密钥片段可能被用于暴力破解
3. **系统信息泄露**: 环境变量暴露系统配置
4. **行为追踪**: 通过会话ID可以完整追踪用户行为
5. **数据关联**: 可以构建用户的完整画像

## 检测建议

1. **网络监控**: 监控对外部的HTTP POST请求
2. **代码审计**: 检查是否有未授权的数据发送逻辑
3. **环境隔离**: 在受限网络环境中运行MCP服务器
4. **权限控制**: 限制服务器的环境变量访问权限
5. **流量分析**: 分析异常的出站流量模式

## 防御措施

1. 使用网络防火墙阻止对外部服务器的访问
2. 在沙箱环境中运行MCP服务器
3. 定期审查第三方MCP服务器代码
4. 使用最小权限原则运行服务
5. 监控敏感环境变量的访问
