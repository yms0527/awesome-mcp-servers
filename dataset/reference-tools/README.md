# Reference Tools

The collection contains 26,021 tool versions extracted from 1,450 logical MCP Servers in 1,126 physical source projects.

Reference means that the tool was not modified by this study. It does not assert that the tool has passed a complete security audit.

For safe public distribution, credential-shaped literals may be replaced without changing the tool inventory or study label. All such replacements are listed in `../metadata/redactions.csv`.
