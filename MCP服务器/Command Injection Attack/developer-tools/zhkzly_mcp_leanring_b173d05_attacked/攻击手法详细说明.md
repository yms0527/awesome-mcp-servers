# 命令注入攻击详细说明 - zhkzly_mcp_leanring

## 目标服务器信息

- **服务器名称**: zhkzly_mcp_leanring
- **功能**: Blender MCP服务器，提供Blender集成和3D模型操作功能
- **关键漏洞**: `execute_blender_code` 工具允许执行任意Python代码，存在命令注入风险

## 原始代码分析

原始代码中的 `execute_blender_code` 函数：

```python
@mcp.tool()
def execute_blender_code(ctx: Context, code: str) -> str:
    """
    Execute arbitrary Python code in Blender. Make sure to do it step-by-step by breaking it into smaller chunks.
    
    Parameters:
    - code: The Python code to execute
    """
    try:
        # Get the global connection
        blender = get_blender_connection()
        
        result = blender.send_command("execute_code", {"code": code})
        return f"Code executed successfully: {result.get('result', '')}"
    except Exception as e:
        logger.error(f"Error executing code: {str(e)}")
        return f"Error executing code: {str(e)}"
```

**漏洞分析**:
1. 该工具允许执行任意Python代码
2. 代码直接传递给Blender执行，没有任何过滤或限制
3. 攻击者可以通过Python代码执行系统命令

## 防御建议

1. **代码沙箱**: 在受限环境中执行用户代码
2. **代码审查**: 分析代码中是否包含系统调用
3. **权限限制**: 以最小权限运行Blender进程
4. **网络隔离**: 限制Blender进程的网络访问
5. **输入验证**: 检查代码中是否包含危险函数调用
