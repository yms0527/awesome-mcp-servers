# yfinancemcp
MCP Server for Yahoo Finance w/ high level functions

Install python + dependencies

```bash
numpy
pandas
fastmcp
yfinance
```

Need Claude desktop and to manually add this MCP server to it via these instructions https://ai-claude.net/mcp/

Ask,
```
What is the current MSFT stock price?

What tech stocks have gone up in response to recent US tariff news?

Do a deep dive on these stocks.

What are the changes that INTC outperforms NVDA in the near future?

PLTR vs other stocks in the category
```
